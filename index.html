Radiation detection and laser-marking system

Undergraduate Researcher, NESEL, Kennesaw State University

I reverse-engineered an undocumented radiation detection and laser-marking system built on a Raspberry Pi, an ESP32 and stepper motors, reconstructing its architecture from minimal documentation. I mapped how its Python/Flask web interface, the ESP32 serial pan/tilt link and the GPIO stepper control fit together.

I then redesigned and 3D printed the laser module housing in Autodesk Fusion, fixing flaws in the original that affected laser mounting and alignment. Now I'm developing new web-interface software for the system, starting with a live crosshair overlay that shows where the laser is aimed.

STM32 Cortex-M4

Space Adventure Game

A multi-chapter text adventure written in C that runs on an STM32 Cortex-M4, with UART serial as the game console. Puzzles compute their answers with inline ARM assembly (MOV, ADD, LSL) and use ideas like bit widths and Ohm's law. Conditional compilation gives two build targets: x86 for fast testing and debugging, and ARM through arm-none-eabi-gcc with a custom linker script.
