Traffic Light Sequencer

A traffic-light controller built entirely from discrete logic: a 555 timer for the clock, a 74LS163 4-bit synchronous counter for state, and decoding gates to drive the lights.

Overview

How it works

The clock

The 555 runs in astable mode, so it outputs a steady square wave. Add your resistor and capacitor values and the resulting frequency, e.g. R1 = ?, R2 = ?, C = ? gives f ≈ 1.44 / ((R1 + 2R2)·C) ≈ ? Hz.

The counter

Each clock edge advances the 74LS163. Because it's synchronous, all four outputs change together on the same edge, which keeps the decode logic glitch-free. Say how many counts the full cycle uses and how you reset it (e.g. using the synchronous CLR pin).

The decode logic

Explain which counts map to red, yellow and green, and the gates you used. A truth table works well here.
