Traffic Light Sequencer

A traffic-light controller built entirely from discrete logic: a 555 timer for the clock, a 74LS163 4-bit synchronous counter for state, and AND-gate decoding to cycle the red and green signals of a four-way intersection.

555 Timer74LS16374LS21Sequential circuits
Intersection

The intersection

The controller runs a four-way intersection with eight signals, A through H. Signals that can safely move together are paired, so the cycle has four phases: A + C, G + E, B + D and H + F. Each signal is either red or green. When its phase is active it turns green, and the rest of the time it stays red.

Overview

How it works

The clock

The 555 runs in astable mode, so it outputs a steady square wave that sets how long each step of the cycle lasts.

The counter

Each clock edge advances the 74LS163. Because it's synchronous, all four outputs change together on the same edge, which keeps the decode logic glitch-free. When the count reaches 8 (1000), output D is inverted into the LOAD pin, so on the next clock the counter loads 0000 and the cycle starts over.

The decode logic

Two 74LS21 chips give me four 4-input AND gates, one per signal pair. Each gate gets the counter outputs, inverted where needed, so it only goes high on its own count: 0001 for A + C, 0011 for G + E, 0101 for B + D and 0111 for H + F.
