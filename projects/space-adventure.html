Space Adventure Game

A multi-chapter text adventure written in C for an STM32 Cortex-M4. The player plays over a UART serial console, and the puzzles compute their answers in inline ARM assembly.

Architecture

How it's built

Dual-target builds

Flashing the board for every change is slow, so the same code also builds for x86. Conditional compilation swaps the input/output layer, which let me test game logic on my laptop and only flash the STM32 for hardware testing.

UART as the game console

The game reads player input and prints story text over UART serial, so any serial terminal on a PC becomes the screen and keyboard. Add baud rate and whether you used polling or interrupts.

Puzzles in assembly

Several puzzles compute their answers with inline ARM assembly (MOV, ADD, LSL) and build on ideas like bit widths and Ohm's law.

Running the puzzle in real ARM assembly

The player sees three ARM instructions and has to work out what ends up in R0. Instead of hardcoding the answer, the game runs those exact instructions with inline assembly and checks against the result.

space-adventure.c · hard_puzzle_asm()Cortex-M4 inline asm
/* hard mode: 20 << 2 = 80, then +1 = 81. LSL by 2 is the same as multiplying by 4 */
int32_t hard_puzzle_asm(void) {
    int32_t result;
    __asm volatile (
        ".syntax unified \n\t"
        "MOV r0, #20    \n\t"
        "LSL r0, r0, #2 \n\t"
        "ADD r0, r0, #1 \n\t"
        "MOV %[out], r0 \n\t"
        : [out] "=r" (result)
        :
        : "r0"
    );
    return result;
}
space-adventure.c · chapter 2 check
if (difficulty == 1) {
    printf("\n--- Chapter 2: The Asteroid Field ---\n");
    printf("Your ship unexpectedly enters the asteroid field...\n");
    printf("What is the decimal value of R0 after the following commands?\n"
           "MOV R0, #20\nLSL R0, R0, #2\nADD R0, R0, #1\n> ");
    strcpy(input, "");
    scanf("%63s", input);
    if (atoi(input) == hard_puzzle_asm()) {   // compare against what the asm actually computed
        printf("\nCorrect! The ship is repaired and you continue on your journey.\n");
        puzzle1_solved = 1;
    } else {
        printf("\nIncorrect! The correct answer was %ld. Game Over.\n", (long)hard_puzzle_asm());
        printf("Please press Enter to return to the main menu.\n");
        while (getchar() != '\n');   // clear out the leftover newline from scanf
        getchar();
        return 0;
    }
}

Ohm's law and bit widths

Later chapters test hardware basics: the max unsigned value of a 4- or 8-bit register, and current through series resistors. The 2.5 A answer is compared as a string because atoi would drop the decimal.

Pronouns that match the player

space-adventure.c · set_pronouns()
// sets he/him/his etc so the crew dialogue matches what the player picked
void set_pronouns(void) {
    if (strcmp(gender, "male") == 0) {
        strcpy(pronoun_subject, "he");
        strcpy(pronoun_object, "him");
        strcpy(pronoun_possessive, "his");
    } else if (strcmp(gender, "female") == 0) {
        strcpy(pronoun_subject, "she");
        strcpy(pronoun_object, "her");
        strcpy(pronoun_possessive, "her");
    } else {
        // anything that isnt male/female just gets they/them
        strcpy(pronoun_subject, "they");
        strcpy(pronoun_object, "them");
        strcpy(pronoun_possessive, "their");
    }
}
